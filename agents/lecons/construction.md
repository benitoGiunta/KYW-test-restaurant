# Leçons construction (portfolio, awwwards, legacy, gabarits)
Nouvelle leçon : une ligne datée à la fin de ce fichier.
- Astro avec `base: /<…>/` : tout lien et asset passe par `import.meta.env.BASE_URL` (helper `u()`/`asset()`, normaliser le `/` final) ; un `url(/…)` d'un CSS vers `public/` ignore la base. Polices auto-hébergées : `?url` dans le layout.
- Aucun balisage JSX dans le frontmatter d'un composant Astro ; ni commentaire HTML dans un composant (il part dans `dist`). Tout code DOM passe par `onPage()` du moteur avec test de présence.
- `<Picture>` : toujours `fallbackFormat="webp"` (dist 18 → 12 Mo). Ne déclarer dans `srcset` que des variantes générées, jamais plus larges que la source ; contrôler tous les `srcset` par `curl` et tester à `deviceScaleFactor: 2`.
- Photos de hero et première photo d'une page intérieure : peintes au premier rendu (`fetchpriority="high"`, ni `lazy` ni `data-reveal`), 960 px pour le hero ; `<picture><source media="(max-width: 767px)">` force la variante mobile.
- LCP : titre et accroche du hero sans `data-intro`, premier bloc de texte sans `data-reveal` ; hero jamais caché en CSS puis révélé par `clip-path` (laisser peint sous le rideau, animer par `transform` et opacité).
- Aucun `data-reveal` sur un bloc contenant un lien ou un bouton (reste hors tabulation) ; pas de deux liens consécutifs de même libellé.
- Un état de départ posé en CSS (`.motion .x { transform … }`) puis `clearProps` laisse l'élément décalé : conditionner par une classe posée au lancement de la timeline ; ne garder que `clearProps: 'transform,opacity'` (jamais `visibility`).
- Timeline GSAP : tweens en positions absolues (`tl.to(p, …, t)`), jamais `'<'` avec durée par glyphe ; pas de tween de `letter-spacing` (CLS) ; animer des écarts par une variable CSS unique (`--ecart`, 1 = état statique) pour avoir repli sans JS et reduced motion.
- Jamais de `setProperty` par frame sur `<html>` ou `<body>` : écrire sur les seuls éléments porteurs visibles (ensemble tenu par `IntersectionObserver`, pas `onToggle`) ; les roues contre-rotées se pilotent par une seule variable (`--rot`).
- `data-split` : `lines,words,chars` pour les titres (jamais coupure en pleine lettre), `lines` pour les citations à `text-indent` négatif ; U+00A0 coupés aussi par SplitText : dernier mot et ponctuation dans un `<span>` nowrap ; `.split-line { padding-top: .16em; margin-top: -.16em }` pour les capitales accentuées.
- Polices : largeur de texte dont la police n'est pas préchargée en `em`, pas `ch` ; italique tardive en `font-display: optional` ; numéros de téléphone en police de texte nowrap ; pas de `tabular-nums` sur prix à virgule ni tableaux de texte.
- Sur un `.wrap`, jamais `margin: X 0` ni `padding: X 0` (annule gouttière/centrage) : `margin: X auto 0` et `padding-block`. Éléments de grille : `min-width: 0` (`.wrap`, `.cols > *`, `.hero__bas`) ; bandes et chips nowrap bornés.
- Hero en grille : `grid-row: 1` explicite des deux côtés ; titre en `grid-column: 1/10` dans un sous-conteneur : `grid-column: auto`. Une variante `--page` redéclare `min-height: 0` dans la même media query ; marges `--silence` et `margin-top` du pied ne se cumulent pas.
- Mesurer avant le shoot, par mini-script : h1, CTA et média à 1440×900, 1280×720, 1024×768, 390×844 ; `left`/`right` de chaque `.display` ; largeur de chaque `<img>` contre son parent ; paires qui se recoupent ; enfants dépassant le `right` du hero ; `scrollWidth` à 320/360/390 ; titres de 3 mots et colonnes en `nowrap`.
- Mobile : barre fixe + CTA de hero = doublon (masquer le primaire sous 40rem) ; `backdrop-filter` sur un header sticky piège une nav `position: fixed` ; grille 12 colonnes repliée : `row-gap` de section ; table restackée : `data-label` + `::before` ; plus de `style="grid-column"` en ligne ; conteneur d'enfants absolus reste `position: relative` ; pin plus haut que le viewport plafonné en `svh`.
- Cibles tactiles : `padding-block` sur liens isolés (pas inline en milieu de paragraphe ; sur inline `padding-block: 2px`) ; un `::after` agrandi ne corrige pas la mesure ; masquer une marque par `clip-path` la laisse focalisable (`display: none`) ; `figure { margin: 0 }` dès la phase 1.
- Horaires et badges : état « ouvert » ou « ce soir » calculé depuis les horaires (jours, créneaux, fermeture) et testé par `page.clock.install` + `timezoneId: 'Europe/Brussels'` à plusieurs instants ; `data-mois` posé avant le premier rendu ; un mois d'horloge ne coiffe que ce qui est mensuel ; un `OpeningHoursSpecification` ne publie que les jours confirmés.
- Contenu adapté : grep de `email`, `avis`, `citation`, `annee` dans `src/` des gabarits dès le scaffold ; plats fictifs remplacés par photos libellées d'après la photo (`nomDescriptif`) ; un champ non prouvé par donnée (`…Placeholder`) ; pastilles « exemple » dans chaque élément de carrousel et dans le hero de page, pas en flux.
- Legacy (Hallmark) : `src/layouts/Base.astro` importe `page.css` par `<style is:global>@import …</style>` ; texte en grille sur un slot `<img>` : `position: relative; z-index: var(--z-raised)` ; iframe tierce (Zenchef) chargée à la demande derrière un bouton avec lien direct ; `thead` visible et discret ; `sites/_test-legacy/` n'existe pas : copier `astro.config.mjs` et `tsconfig.json` d'un site frère.
- Lenis émet `scroll` avant le premier `onPage()` : tolérer l'absence des clés ; loader limité à l'accueil : poser `is-loaded` s'il est absent.
- Reveal « une fois » par `IntersectionObserver` (`animation-timeline: view()` se rejoue à l'envers) ; en reduced motion, repli statique sans texte caché ; lien d'évitement fixe en `translateY(calc(-100% - var(--gutter)))`.
- Gabarits : corriger avant réutilisation les défauts connus (écho `inert` et footer sous `#fond` de quatre-mains, `ch` et escalier mobile de verger, barre d'état d'ardoise) ; copier `src/engine/`, `engine.css`, `menu.ts`, `url.ts`, `Photo.astro` d'un site awwwards frère ; `gabarits/` protégé : noter dans ETAT.md.
- sloplint : `sloplint src --genre editorial --url <page>` depuis le dossier du site, jamais sur `dist/**/*.html` (faux FAIL 26a/34/76) ; waiver « gate · preuve · raison » ; `--kept` ne compare rien (câblage à la main) ; `--render` échoue en root, le signaler.
- Contraste : pas d'opacité sur texte posé sur l'accent ; accent clair pour surfaces seulement ; palettes `oklch()` : convertir par canvas 1×1 avant calcul.
