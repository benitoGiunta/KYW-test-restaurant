# Leçons reviseur-site
Nouvelle leçon : une ligne datée à la fin de ce fichier.
- Avant de corriger un finding, relire le prompt de la variante : refuser en citant le paragraphe s'il le contredit ; ne retoucher le code qu'après `grep` dans `dist/` si un réviseur précédent a été coupé (src/ et DESIGN.md sont alors à jour).
- Un correctif de performance se mesure en série avant d'être déclaré fait ; chronométrer d'abord `DOMContentLoaded`, `responseEnd` du gros module et `is-loaded` ; un `modulepreload` injecté après build ne gagne rien.
- Un rebuild pendant un shoot de fond vide `dist/` : préparer les corrections, rebuilder après DONE ; ne pas rebuilder un gabarit sans recopier son `apercu.png`.
- Mobile : titres plafonnés sur le mot le plus long (`vertical-rl` : `nowrap`) ; frise sticky : réserver la hauteur des libellés ; bandeau « exemple » dans le hero de page, pas en flux ; pas de padding sur la `figure.vignette` elle-même (border-box mange l'image) ; un fit remonte au parent en sautant `display: contents`.
- CLS d'une police tardive : `font-display: optional` (en/em et preload ne suffisent pas sous 4G lente) ; LCP mobile : `<picture>` 560 px, hero 960 px (~65 Ko).
- Un relecteur peut exiger une image plus grande que l'original : vérifier la taille dans `data/restaurants/<slug>/photos/` ; générer les variantes manquantes depuis le JPG (`sharp … webp({quality: 80})`), jamais plus large que la source ; avant de neutraliser un alt, lire `photos/index.json`.
- Apostrophes et `oe` : Python, `\p{L}`, lister les mots touchés, recompter sur `dist/` après build ; pas de `perl` sans `use utf8`.
- Contenu sans source (bon cadeau, privatisation, réservation) : réduit au fait du dossier, montants marqués illustratifs, aucun canal ni procédure ajoutés ; un `<span class="illu">` après une expression Astro perd son espace de tête : marge CSS.
- Corriger une cause structurelle (écho `inert`, footer sous `#fond`, `.wrap`) dans le gabarit aussi ; un en-tête à deux copies se répare avec de vrais `<a tabindex="-1">` sous `aria-hidden` et deux clip-path complémentaires, preuve par 30 `page.mouse.click`.
- Legacy : `sloplint src --url <page>` depuis le dossier du site (sinon waivers ignorés) ; `audit.mjs` par URL sur `serve.mjs dist` ; polices Google : `curl` du CSS avec User-Agent Chrome pour les woff2 latin ; un lien long en police d'affichage dans le pied déclenche REFLEX 49b.
- 01/11/2026 · Un lien ajouté pour une correction (ex. `.link` dans une carte d'accent) hérite d'une couleur pensée pour le fond papier : recalculer son contraste sur le fond réel de la carte (oklch → luminance) avant de conclure ; chez-guillaume legacy : bleu 4,32:1 sur rose, passé en encre.
- 01/11/2026 · axe `aria-prohibited-attr` sur des `p`/`span[data-split]` : c'est le `aria: 'auto'` par défaut de `SplitText.create` (aria-label sur un élément sans rôle) ; passer `aria: 'none'` quand seul `lines`/`words` est utilisé. Un logo à `aria-label` dont une case visible change (section) déclenche `label-content-name-mismatch` : nom en `sr-only`, cases `aria-hidden`, pas d'`aria-label`. `loaderMs` de shoot.mjs part de la navigation : chronométrer DCL et début du compteur avant de promettre un gain (chez-guillaume portfolio : loader 2,25 s, mais 2,4 s de JS avant).
- 01/11/2026 · Légacy : un bloc de corrections CSS ajouté en fin de `page.css` (après le `@import`) suffit pour F2 de mise en page ; `object-position` posé en style inline par `Fig.astro` ne se surcharge en media query qu'avec `!important`. Mesurer les « zones vides » par `padding` cumulés des sections voisines (bas + haut = 288 px), pas à l'œil.
- 01/11/2026 · dolce-vita-wepion portfolio : loader masqué en CSS sous 768 px mais engine/loader.ts attendait quand même MIN ; sur 4G lente `is-loaded` = DCL (+50 ms), le temps est réseau (script moteur 155 Ko en concurrence avec polices et photo du hero). Mesurer `is-loaded` et `responseEnd` avant de promettre un gain. Une `ul` sans `padding-left: 0` décale d'environ 40 px la liste de remplacement des cartes.
- 01/11/2026 · dolce-vita-wepion awwwards : `aria-prohibited-attr` sur `data-split` = `aria: 'none'` dans `SplitText.create` (déjà noté, à appliquer dès la construction) ; une région `overflow-x: auto` mobile exige `tabindex=0` + `aria-label` (+ `role=region` sur un div).
- 07/11/2026 · le-royal legacy : un héros dont la photo remplit une colonne en `object-fit: cover` étire une source étroite ; donner à la figure l'`aspect-ratio` de la source plutôt qu'une hauteur d'écran. Polices Google : auto-héberger les woff2 latin (curl du CSS avec UA Chrome), `font-display: optional` + preload ramène le CLS mobile à 0 sous 4G lente.
- 2026-11-07 · le-royal awwwards : le composant `kyw-footer` porte déjà le `<footer>` de la page ; un pied de site en `<footer>` aussi donne l'axe `landmark-no-duplicate-contentinfo` : le rendre en `<section aria-label="Contact et horaires">`. Un F2 de contenu (phrase répétée, aveu, donnée non prouvée) se prouve par `grep` sur `dist/` après build (0 occurrence), y compris le script du moteur ; une donnée douteuse se retire de la page et reste dans `site.ts`.
- 2026-11-07 · incorrect portfolio : un titre masqué par SplitText grandit de 0,08 em (padding-bottom de la dernière ligne) à la découpe et provoque un CLS d'environ 0,07 sur un hero aligné en bas : réserver `padding-bottom: .08em` avant la découpe et le retirer par une classe posée dans `onSplit`. Mesurer les débordements de grille par `getBoundingClientRect` des cartes (pas `scrollWidth` de page, masqué par `overflow-x: clip`), en excluant les transformations de reveal en cours (scale 1,15).
- 2026-11-07 · incorrect portfolio : un texte display étiré (font-stretch 125%) dans une demi-colonne ou un cadre se dimensionne en `cqi` du conteneur (`container-type: inline-size`) ; `vw` seul déborde en tablette. `overflow-x: clip` masque ces débordements : mesurer `scrollWidth > clientWidth` des cartes et `Range.getClientRects` des mots, à 768/1024/1440, pour chaque composant réutilisé sur plusieurs pages.
- 2026-11-07 · l-essentiel legacy : axe `label-content-name-mismatch` persiste si le texte visible est fait de deux éléments sans espace (« L’Essentiel<span>Temploux</span> » = « L’EssentielTemploux ») : insérer un vrai espace dans le balisage, pas seulement ajuster l'aria-label.
- 2026-11-07 · l-essentiel portfolio : un cadre 4:5 rogne une enseigne plus large que haute ; vérifier la largeur du sujet dans la source avant de fixer le ratio du hero (ici 5:6). Axe `region` : éléments fixes (logo vertical, pastille) dans un `<aside aria-label>` ; `<footer>` du site en `<section aria-label>` à cause de kyw-footer. LCP desktop avec loader : la sortie du loader (0,7 + 1 s) pèse autant que le réseau ; la raccourcir vaut preload.
- 2026-11-07 · l-essentiel awwwards : `is-loaded` n'apparaît pas toujours sur la page réservation (waitForFunction expire à 30 s) ; pour une mesure de mise en page, utiliser waitForTimeout(3500) plutôt que d'attendre la classe.
- 2026-11-07 · l-essentiel portfolio : un h1 en SplitText dont le conteneur a un max-width fixe est tronqué aux grands écrans (texte 452 px dans 370) : mesurer boîte vs texte à 1440, 1536, 1920, 2560 ; une grille à une colonne implicite exige `minmax(0, 1fr)`. La commande de build est `pnpm build:site`.
- 2026-11-09 · ferme-blanche-d-asie legacy : sloplint --genre n'accepte que editorial, modern-minimal, atmospheric, playful (pas « restaurant ») ; `getClientRects().length` d'un inline contenant un élément enfant compte plusieurs rectangles même sur une ligne : mesurer la hauteur de boîte.
- 2026-11-09 · ferme-blanche-d-asie portfolio : `<footer>` du site en `<section aria-label>` suffit pour axe `landmark-no-duplicate-contentinfo` (kyw-footer porte le contentinfo) ; recompresser un WebP 1400 px à q60 donne ~250 Ko, passer à 1280 px q62 pour descendre sous 225 Ko.

- Un correctif qui rend visible un élément masqué à 390 px (nom de l'en-tête) peut déborder à 360 px (+25 px mesurés). Mesure `scrollWidth` à 390 ET 360 px après la correction ; sous 24 rem, repasse en visually-hidden (le lien garde son `aria-label`). `is-loaded` n'apparaît pas toujours en mobile : un `waitForTimeout(2500)` suffit pour une mesure axe.
- 2026-11-10 · le-felicien portfolio : un `gsap.to(el, { overwrite: true })` tue aussi les `quickTo` posés sur le même élément ; utiliser `overwrite: 'auto'`. Un h2 `display:none` (onglets) casse l'ordre des titres pour axe : le passer en visually-hidden.
- 2026-11-10 · le-felicien awwwards : SplitText en overflow clip coupe les accents des capitales : ajouter padding-top .2em / margin-top -.2em à .split-line dès la construction ; un h1 display à line-height < 1 sur deux lignes accentuées veut ≥ 1,05 (0,95 collait encore).
- 2026-11-10 · le-felicien legacy : un `scrollIntoView` au chargement (onglets) déplace le point de départ du Tab vers le pied de page ; ne l'appeler que sur action. Un `footer` passé en `div` sort du repère (axe `region`) : prendre `section aria-label`.
- 2026-11-10 · grill-des-amis portfolio : `0{i + 1}` donne « 010 » dès 10 éléments (carte à 10 plats) ; utiliser `String(i + 1).padStart(2, '0')` ; vérifier aussi le gabarit Braise.
- 2026-11-10 · grill-des-amis legacy : CLS d'un hero dû à Google Fonts swap : auto-héberger en woff2 latin (pip install fonttools brotli, pyftsubset ; TTF via css2 avec un UA ancien) + preload ; 0,065 devient 0,000. Un pied de site en `section aria-label` règle axe contentinfo.
- Retirer un élément d'une page : chercher les règles de grille qui réservaient sa colonne (`.plat` à 2,5 rem) et `aria: 'none'` de SplitText démasque les mots à axe `color-contrast` : relever la couleur d'attente des mots en même temps.
- 2026-11-10 · grill-des-amis awwwards : `white-space: nowrap` sur un `small` en `display: block` n'a aucun effet (le bloc occupe sa ligne) ; passer en `inline`/`inline-block` ou l'unité dans la description, et capturer le mobile avant de déclarer corrigé.
- 2026-11-10 · le-54 legacy : un lien inline mesuré 21 px se corrige par `display:inline-block; padding-block:.2rem` (rect = 27 px, pas de débordement à 360).
- 2026-11-10 · le-54 portfolio : un aria-label sur un lien dont le texte visible est masqué sous 768 px provoque `label-content-name-mismatch` en desktop ; utiliser visually-hidden sur le texte. Ne jamais lancer `git stash` pour comparer avec l'état d'avant : l'arbre est partagé avec d'autres agents.
- 2026-11-10 · le-54 awwwards : `<picture>` rend `height:100%` d'une `img` inopérant ; ajouter `picture{display:block;width:100%;height:100%}` dans tout cadre à ratio fixe, mesurer img vs figure à 390/768/1440.
- 01/11 (révision le-ponti-2) : un LCP mobile venant d'une image 1448 px s'est corrigé par une variante 800 px + srcset + fetchpriority (3,6 s → 2,05 s) ; mesurer en 2 passes avec CDP (CPU x4, 4G lente).
- Remplacer un `<footer>` dupliqué par un `<div>` fait apparaître axe `region` (contenu hors repère) : utiliser `<section aria-label="…">`. Chromium Playwright en script maison : `launch({executablePath:'/opt/pw-browsers/chromium-*/chrome-linux64/chrome'})`, sinon « npx playwright install » est réclamé.
- Révision ciblée : un h1 coupé en milieu de mot se mesure par script (largeur nowrap de chaque mot vs clientWidth du h1) à 360/390/768/1440 px sur toutes les pages ; le sed d'un texte avec espace insécable échoue : utiliser une regex Python.
- 2026-11-10 · le-servais portfolio : un LCP mobile de héros se mesure avec deviceScaleFactor 2 (comme shoot.mjs) ; un `srcset` 600w/900w avec `sizes` 60vw en mobile a ramené 3,5 s à 2,25 s ; un loader se raccourcit par MIN, lissage (0,12/image ajoute ~0,7 s) et durées de sortie.
- 2026-11-10 · le-servais legacy : un h1 display étiré (Anybody, `font-stretch`) coupé en milieu de mot se corrige par `clamp()` en vw sous 48 rem et `overflow-wrap: normal`, mesuré par script (mot le plus large vs h1) sur toutes les pages à 360/390/768/1440 ; un contenu repris d'un post client voisin (« concerts gratuits ») se retire après `grep` de `dist/`.
- 2026-11-10 · le-servais awwwards : les procédures déduites (« par téléphone ou par e-mail », « 4e offert », « Trois façons ») et un décompte de lignes de carte (« 76 lignes ») se réécrivent sur le dossier ; un champ de données passé à `null` fait disparaître le composant sans toucher au gabarit ; vérifier par `grep` de `dist/` que l'ancienne phrase est absente.
- 10/11/2026 : une règle d'image `height:100%` ne s'applique pas à un `<img>` dans un `<picture>` inline (astro:assets) : donner `display:block;height:100%` au picture, sinon object-position est sans effet.
